PROJECT HIGHLIGHT


Overview

DeskOps is a full-stack helpdesk and ERP system built from scratch, solo, running on a local WAMP stack (Windows, Apache, MySQL, PHP). What started as a structured ticketing tool grew into a platform with a full financials module, role-based access control, SLA monitoring, knowledge management, and a RAG-powered AI research layer.

The AI layer integrates ChromaDB for vector storage, Gemini and Groq as the primary LLM providers through a multi-model fallback chain, and a two-pass citation pipeline that screens RAG chunks for relevance before feeding them into structured resolution note generation. The system is capable of indexing attachments, querying them semantically, and producing research-grade outputs grounded in sourced evidence.

Tech Stack

PHP 8 MySQL JavaScript (Vanilla) HTML / CSS ChromaDB Python Gemini API Groq API NVIDIA NIM WAMP Stack

Key Features

Role-Based Access Control

Tiered access across IT support levels (Tier 1 through 4) and admin, with permission-scoped views, actions, and escalation paths.

SLA Monitoring

Automated SLA tracking with color-coded urgency indicators, breach prediction, and escalation triggers.

Knowledge Base

Structured article management with tagging, categorization, and AI-assisted tag profiling for context-aware surfacing.

Financials Module

Full ERP-lite financials covering Invoices, Expenses, Ledger, Budget, Chart of Accounts, and an SVG-based analytics dashboard.

RAG Pipeline (Ask AI)

Attachments are indexed into ChromaDB via Python. Per-session chat history, semantic retrieval, multi-model fallback (Gemini, NVIDIA NIM, Groq), and inline citation tracking are all built in.

AI Resolution Notes

Two-pass generation: Pass 1 screens RAG citations for relevance using a structured prompt. Pass 2 writes the resolution note grounded in pre-screened evidence, using Cynefin domain classification, Bloom's Taxonomy level, and DOT research strategy as silent reasoning frameworks. Citations are persisted to MySQL and rendered inline.

Attachment Manager

Upload, gallery preview, password protection, bundle management, and per-file ChromaDB indexing status tracking.

In Action (Episode 1)
